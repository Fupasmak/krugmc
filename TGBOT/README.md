# TGBOT — Telegram-бот KRUG

Node + [grammY](https://grammy.dev). Отвечает за три вещи:

1. подтверждение входа зрителя на сайт по deep-link `?start=login_<token>`;
2. привязку Telegram к аккаунту игрока `?start=link_<token>`;
3. проверку подписки на канал `@serverKRUG` — сайт спрашивает бота
   перед тем, как принять голос.

Токен бота живёт только здесь: сайт его не знает и в Telegram напрямую не ходит.

---

## Создание бота

1. Открой [@BotFather](https://t.me/BotFather) → `/newbot` → имя и username.
   Уже созданный бот проекта: `@KRUGSERVER_BOT`.
2. Получи токен → положи в корневой `.env`:

   ```
   TG_BOT_TOKEN=<токен>
   TG_BOT_USERNAME=KRUGSERVER_BOT
   ```

3. `/setdomain` → `krugmc.ru`.
4. `/setcommands` заполнять руками не нужно: бот сам ставит список при старте.

> Если токен куда-то утёк — сразу `/revoke` в BotFather и новый токен в `.env`.
> Старый перестаёт работать немедленно.

## Бот в канале

Чтобы работала проверка подписки:

1. Открой канал `@serverKRUG` → «Администраторы» → «Добавить администратора».
2. Добавь `@KRUGSERVER_BOT`. Права можно снять все, кроме самого факта
   администрирования — читать список участников бот может только так.
3. Проверить: напиши боту `/status`. Ответ «Подписка есть/нет» означает, что
   `getChatMember` работает. Ошибка — бот не админ канала.

## Запуск

Из корня монорепо:

```bash
npm install
npm run dev:bot
```

Прод:

```bash
npm run build --workspace=TGBOT
npm run start --workspace=TGBOT
```

В Docker бот поднимается сервисом `bot` из `docker-compose.yml`.

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `TG_BOT_TOKEN` | токен от BotFather |
| `TG_BOT_USERNAME` | username без `@`, из него сайт строит deep-link |
| `TG_CHANNEL` | канал для проверки подписки, по умолчанию `@serverKRUG` |
| `SITE_URL` | публичный адрес сайта, показывается в сообщениях |
| `SITE_INTERNAL_URL` | адрес сайта для внутренних вызовов (`http://web:3000` в Docker) |
| `INTERNAL_API_SECRET` | общий секрет HMAC с сайтом |
| `BOT_INTERNAL_PORT` | порт внутреннего сервера, к нему ходит сайт |
| `BOT_MODE` | `polling` (по умолчанию) или `webhook` |
| `BOT_WEBHOOK_URL`, `BOT_WEBHOOK_PORT`, `BOT_WEBHOOK_SECRET` | только для webhook |

## Внутренний API бота

`POST /internal/subscription` — запрос от сайта, подписан HMAC:

```json
{ "tgId": "123456789" }
```

Ответ:

```json
{ "ok": true, "subscribed": true }
```

`GET /health` — проверка живости, без подписи.

Подробности подписи — в корневом `API.md`.

## Проверка руками

1. Напиши боту `/start` — должно прийти приветствие со ссылкой на сайт.
2. На сайте нажми «Войти через Telegram» — бот пришлёт кнопку подтверждения.
3. Нажми её — вкладка сайта войдёт в аккаунт сама.
4. `/status` — покажет, видит ли бот твою подписку на канал.
