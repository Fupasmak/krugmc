# Плагин KRUG (Paper 26.2)

Одна задача: игрок пишет в чате `/krug login КОД` — сайт `krugmc.ru`
понимает, что это он, и пускает в аккаунт.

- Платформа: Paper 26.2, Java 25
- Сообщения: Adventure MiniMessage, тексты в `config.yml`
- Сеть: асинхронно, основной поток сервера не блокируется
- Подпись запросов: HMAC-SHA256 общим секретом с сайтом

## Сборка

Нужен JDK 25.

```bash
cd minecraft
./gradlew build
```

Готовый файл: `minecraft/build/libs/krug-1.0.0.jar`.

Wrapper лежит в репозитории, отдельно ставить Gradle не нужно: хватит JDK 25
в `JAVA_HOME`. На Windows команда пишется `gradlew.bat build`.

## Установка

1. Положи jar в `plugins/` сервера.
2. Запусти сервер — появится `plugins/KRUG/config.yml`.
3. Заполни конфиг:

```yaml
server:
  # Адрес подключения: айпи или домен с портом. Нужен только для /krug ip
  address: "play.example.ru:25565"

api:
  url: "https://krugmc.ru"
  secret: "тот же самый MC_HMAC_SECRET, что в .env сайта"
```

Адрес сайта и адрес сервера меняются здесь же, пересобирать jar не нужно:
правишь `config.yml`, делаешь `/krug reload`. Тот же адрес сервера заводится
в админке сайта, раздел «Настройки»: там он лежит для админов и ни на одну
страницу не выводится.

4. `/krug reload` или перезапуск сервера.

Секрет генерируется так:

```bash
openssl rand -hex 32
```

Если секрет не совпадёт с сайтом, сайт ответит `bad_signature`, а игрок
увидит «Код не найден». В консоли сервера будет предупреждение.

## Команды

| Команда | Право | Что делает |
|---|---|---|
| `/krug login <код>` | `krug.login` (всем) | подтверждает вход на сайт |
| `/krug site` | всем | присылает кликабельную ссылку на сайт |
| `/krug ip` | всем | присылает адрес сервера из конфига |
| `/krug reload` | `krug.admin` (оп) | перечитывает `config.yml` |

Код — шесть символов, живёт 5 минут, одноразовый. Игрок берёт его на
странице входа сайта.

## Что уходит на сайт

```json
{
  "code": "ABC123",
  "uuid": "07e0d0c2-...",
  "nickname": "Fupasmak",
  "textures": "<значение свойства textures из профиля>"
}
```

Заголовки: `X-KRUG-Timestamp`, `X-KRUG-Nonce`, `X-KRUG-Signature`.
Подпись считается по строке `<timestamp>.<nonce>.<тело>`, окно — 60 секунд,
nonce одноразовый. Подробности — в корневом `API.md`.

Скин сайт вырезает из текстуры сам, плагин отдаёт только значение `textures`
из профиля игрока. Сервер лицензионный, поэтому профиль приходит от Mojang
при входе и SkinsRestorer не нужен: интеграция с ним не делалась.

## Сообщения игроку

Все тексты лежат в `config.yml`, раздел `messages`, и правятся без пересборки.
Поддерживается MiniMessage: `<green>`, `<bold>`, `<click:open_url:'...'>`.

## Проверка

1. На сайте нажми «Войти через Minecraft» — появится код.
2. В игре: `/krug login КОД`.
3. В игре — «Вход подтверждён», вкладка сайта входит в аккаунт сама.
4. Ошибки: истёкший код, чужой код, неверный секрет — каждая со своим текстом.
