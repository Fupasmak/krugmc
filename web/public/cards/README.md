# Карточки игроков

Здесь лежат PNG-карточки, которые показываются на странице «Игроки»
и в профиле игрока.

## Именование

```
<ник в нижнем регистре>.png
```

Примеры: `fupasmak.png`, `oak_serega.png`.

Ник берётся тот же, что на сервере. Регистр не важен при загрузке через
админку: файл всё равно сохранится в нижнем регистре.

Если файла нет, сайт показывает `_placeholder.png`.

## Требования к файлу

| Параметр | Значение |
|---|---|
| Формат | PNG |
| Соотношение сторон | 2:3 (вертикальная) |
| Рекомендуемый размер | 800 × 1200 |
| Минимум | 400 × 600 |
| Вес | до 5 МБ |

Картинка любого размера подгоняется сама: при загрузке через админку она
обрезается по центру до 800 × 1200. Если кладёшь файл руками, лучше сразу
готовить в 2:3, иначе обрезка будет на стороне браузера по тем же правилам
(`object-fit: cover`).

## Как добавить

**Через админку:** `/admin` → «Игроки» → игрок → «Загрузить карточку».
Так надёжнее: файл сам приведётся к нужному размеру и пропишется в базе.

**Руками:** положить файл в эту папку с правильным именем. На странице он
появится сразу, но в базе `cardFile` останется пустым это нормально,
сайт сначала ищет файл по нику.

## Заглушки

- `_placeholder.png`: показывается, если карточки нет. Не удалять.
- `_example-1.png`, `_example-2.png`: примеры оформления и пропорций,
  можно удалить.
