# Что сделано и что осталось

Состояние на 17 сентября 2026.

## Готово полностью

**Общее**

- Монорепо на npm workspaces: `web`, `TGBOT`, `minecraft`.
- Единый `.env` в корне, `.env.example` с комментариями ко всем переменным.
- `docker-compose.yml`: база, сайт, бот, nginx с HTTPS и лимитом 200 МБ на загрузку.
- Dockerfile для сайта и бота, `.dockerignore`.
- Первая миграция базы лежит в репозитории
  (`web/prisma/migrations/20260917000000_init`).
- `npm run typecheck` и `npm run lint` проходят без ошибок и предупреждений,
  `npm run build` собирает сайт и бота.

**Сайт**

- Вход через Minecraft: одноразовый код на 5 минут, привязка к вкладке,
  подпись HMAC, защита от повторов, лимиты попыток.
- Вход через Telegram: deep-link на бота с кнопкой подтверждения.
- Подтверждение прилетает потоком SSE, при обрыве — опрос статуса.
- Сессии: httpOnly + SameSite cookie, хеш токена в базе, «выйти везде».
- CSRF: проверка Origin плюс двойная отправка токена.
- Привязка и отвязка Telegram в личном кабинете.
- Завозы: создание с четырьмя вложениями (фото 5 МБ, видео 200 МБ, потоковая
  загрузка с прогрессом), правка с пометкой «изменено», мягкое удаление,
  метки «На стриме» / «Вне стрима», лента с фильтром и страницами.
- Голосование: только зрители из Telegram с подпиской на канал, один голос
  навсегда, уникальный индекс в базе, кэш подписки, кнопки «Подписаться» и
  «Я подписался, проверить».
- Игроки: карточки PNG (из базы или по имени файла), поиск, три сортировки,
  страница игрока с головой скина, UUID, датой первого входа, текстом и завозами.
- Головы скинов: сервер вырезает лицо и второй слой, кэширует, отдаёт любым
  размером; своя голова по умолчанию, если скина нет.
- Главная: слоган, круг из блоков, статус проекта, трейлер с YouTube,
  последняя неделя архива, «Завозчики недели», лента, блоки о проекте.
- Архив: недели, черновики и публикация, плитка записей с фильтром по типу.
- Медиа: витрина роликов с фильтром по автору.
- Тексты: «Что такое KRUG», «Zero Season» (13 разделов, оглавление,
  левитирующие блоки), «Как попасть», «Угол» — правятся из админки.
- Вики: статьи по разделам, черновики, страницы `/wiki` и `/wiki/<slug>`.
- Админка: сводка и аудит-лог, игроки (добавление заранее, карточки, скрытие,
  роли, удаление незашедших), завозы (закрепить, удалить, вернуть), архив,
  медиа, вики, тексты, настройки.
- 404 «Чанк не прогрузился», `robots.txt`, `sitemap.xml`, Open Graph, favicon.
- Дизайн: тёмная тема, кислотно-зелёный акцент, кнопки-блоки с пиксельными
  гранями и вдавливанием, панели-слоты, свой пиксельный шрифт для заголовков,
  Onest для текста, свои иконки 9×9 и текстуры 16×16, адаптив от 360px,
  меню-инвентарь на мобиле.
- Безопасность: проверка типов файлов по сигнатуре, санитайзинг Markdown,
  ограничение частоты в базе, защита путей загрузок, скины только с домена Mojang.

**Бот**

- Подтверждение входа и привязки по deep-link с кнопками.
- Проверка подписки через `getChatMember` по запросу сайта (внутренний HTTP
  с подписью HMAC), команда `/status` для самопроверки.
- Перенос аватара в сайт байтами, чтобы не хранить ссылку с токеном бота.
- Long polling по умолчанию, режим webhook переключается переменной.

**Плагин**

- `/krug login <код>`, `/krug site`, `/krug reload`, автодополнение команд.
- Асинхронные запросы, подпись HMAC, понятные сообщения на каждую ошибку.
- Тексты и адрес сайта в `config.yml`, Adventure MiniMessage.

**Документация**

- `README.md` — запуск и деплой по шагам.
- `API.md` — все эндпоинты, подпись, лимиты.
- `DATA_SCHEMA.md` — таблицы и связи.
- `docs/TESTING.md` — сквозная проверка руками.
- `minecraft/README.md`, `TGBOT/README.md`, `web/public/cards/README.md`.

## Не сделано и почему

| Что | Почему |
|---|---|
| **Прогон вживую** (вход, голосование, загрузки) | На машине сборки нет PostgreSQL и Docker, поднять базу было негде. Код собирается и проходит проверку типов, но сценарии из `docs/TESTING.md` надо пройти на первой машине с базой. |
| **Сборка jar плагина** | Нужен JDK 25, на машине стоит только Java 8. Исходники и `build.gradle.kts` готовы, сборка — `gradle wrapper && ./gradlew build`. |
| **Gradle wrapper в репозитории** | Файл `gradle-wrapper.jar` нельзя сгенерировать без установленного Gradle. Команда для создания есть в `minecraft/README.md`. |
| **Раздел «Команда»** | Отложен по твоей просьбе. Страница `/team` и таблица в базе есть, включается флагом `FEATURE_TEAM`, интерфейса управления составом нет — записи пока добавляются прямо в базе. |
| **Сабсервер «Угол»** | Пока это инфо-страница за флагом `FEATURE_CORNER=false`: сервера ещё нет, механики проходок тоже. |
| **Механика Zero Season** (баллы, иммунитет, «Отсчёт», голосования за исключение) | Ты сказал «там просто инфа», поэтому это текстовая страница. Если понадобится живой подсчёт баллов и выбывания — это отдельная итерация с таблицами и админкой. |
| **Вики как на Fandom** (правки всеми, история версий, откаты) | Сделаны статьи, которые пишет администрация. Полноценный движок правок — отдельная большая работа, в план не входила. |
| **SkinsRestorer** | Сервер лицензионный, профиль с текстурами приходит от Mojang при входе. Интеграция не нужна и не делалась. |
| **Уведомления в канал о новых завозах** | Ты ответил «не надо». |
| **Онлайн-статус сервера** | Ты ответил «не надо». |
| **Светлая тема** | Только тёмная, по твоему ответу. |
| **Обложки для видео-вложений** | Кадр из видео вытащить нечем — для этого нужен ffmpeg в образе. Вместо обложки показывается сам плеер с меткой «видео». |

## Что нужно от тебя перед запуском

1. **Отозвать токен бота**, который ты присылал в чате: @BotFather → `/revoke`,
   новый токен в `.env`. Прежний считай публичным.
2. Добавить `@KRUGSERVER_BOT` администратором канала `@serverKRUG`.
3. Купить домен `krugmc.ru` и VDS, направить A-запись на сервер.
4. Заполнить боевой `.env`: пароль базы, три секрета, токен бота.
5. Прописать `MC_HMAC_SECRET` в `plugins/KRUG/config.yml` на сервере Minecraft.
6. Прислать нормальные тексты «Что такое KRUG» и «Zero Season» — я заменю
   черновики (или правь сам через `/admin` → Тексты).
7. Дать ссылку на трейлер YouTube — вставляется в `/admin` → Настройки.
